# AI Usage Documentation

## Alat Bantu AI

AI digunakan sebagai alat bantu pembelajaran selama pengerjaan Praktikum Pemrograman Backend Lanjut.

AI yang digunakan:

* ChatGPT
* Gemini

## Bagian yang Dibantu

### 1. Persiapan Environment

AI membantu:

* Membantu memahami error ketika menjalankan program Go.

### 2. Variabel dan Struktur Data

AI membantu menjelaskan dan memberikan contoh implementasi mengenai:

* Deklarasi variabel.
* Penggunaan slice.
* Penggunaan map.
* Operasi menambah data pada map.
* Membaca data map dengan pengecekan keberadaan key.
* Menghapus data menggunakan `delete`.
* Menelusuri isi map menggunakan `range`.

### 3. Pointer

AI membantu menjelaskan:

* Konsep pointer pada Go.
* Perbedaan pass by value dan pass by pointer.
* Alasan perubahan nilai pada pass by value dan pass by pointer menghasilkan keluaran yang berbeda.

### 4. Struct Student

AI membantu menjelaskan:

* Perbedaan value receiver dan pointer receiver.
* Alasan penggunaan value receiver pada `GetInfo()`.
* Alasan penggunaan pointer receiver pada method yang mengubah data Student.

## Kontribusi Mahasiswa

Kode program dijalankan dan diuji oleh mahasiswa pada komputer sendiri.

Mahasiswa bertanggung jawab untuk:

* Menyiapkan environment pemrograman.
* Menulis dan/atau menyesuaikan kode program.
* Menjalankan setiap program.
* Memeriksa keluaran program.
* Memahami konsep yang digunakan.
* Melakukan commit dan push ke repository GitHub.
* Menyusun laporan praktikum.

AI digunakan sebagai alat bantu pembelajaran dan bukan sebagai pengganti pemahaman terhadap kode.

## Ringkasan

Bantuan AI digunakan terutama untuk memahami konsep, mendapatkan contoh implementasi, troubleshooting, dan dokumentasi. Seluruh kode yang digunakan dalam praktikum diperiksa, dijalankan, dan diuji oleh mahasiswa.
